# PearlCatch (Fabric 1.21.11)

Бинд на технику **pearl-catch**: одно нажатие → сначала эндер-жемчуг,
мгновенно за ним ветряной заряд. Слот в хотбаре возвращается автоматически.

## Сборка
Нужен JDK 21. Если gradlew.bat нет в архиве — скачай wrapper jar:

    mkdir gradle\wrapper
    curl -L -o gradle\wrapper\gradle-wrapper.jar https://services.gradle.org/distributions/gradle-9.8.0-wrapper.jar

Затем:

    gradlew build

Готовый jar: `build/libs/pearlcatch-1.0.0.jar` → кидаем в `mods`
вместе с Fabric Loader 0.19.3+, Fabric API 0.141.4+1.21.11 и VulkanMod.

## Настройка
Бинд по умолчанию — **G**. Меняется в Настройки → Управление → категория «PearlCatch».

## Как это работает (и почему срабатывает с первого раза)
Мод НЕ имитирует нажатия клавиш и не полагается на тайминги игры.
При нажатии бинда в одном клиентском тике происходит:

1. клиент сам выставляет слот с жемчугом и шлёт `UpdateSelectedSlotC2SPacket`;
2. сразу вызывается `interactionManager.interactItem(...)` — пакет использования уходит следом;
3. то же самое для ветряного заряда;
4. на следующем тике возвращается исходный слот.

Порядок пакетов гарантирован TCP, поэтому сервер всегда обрабатывает
жемчуг раньше винчарджа — без «срабатывает раз с десятого».

## Совместимость
Мод клиентский и не трогает рендер — с VulkanMod конфликтов нет.
Требования: Fabric Loader >= 0.16.0, Fabric API любой для 1.21.11, Java 21.

## Внимание
Это макрос на отправку легитимных пакетов. На серверах с античитом
или правилами против макросов его использование может быть запрещено.
